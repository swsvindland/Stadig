# AGENTS.md

The instructions for coding agents working in this repository are in [CLAUDE.md](CLAUDE.md). Read it in full before changing anything: it has the commands, where code goes, the Swift and SwiftUI conventions, the tests a change needs, and how to work beside other sessions in the same checkout.

- [agent-docs/](agent-docs/README.md) holds the notes agents keep: calls that need the owner's check, and what was verified by hand.
- [docs/](docs/README.md) is for people: how the apps work and how to build them. Keep it current when behaviour changes.
- `.claude/skills/` has step-by-step skills (build and test, run an app, add a feature, review, commit, release). They're plain Markdown, so any agent can follow them.
